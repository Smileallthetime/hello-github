# Oracle 练习环境速查

> 每次开机后要学 Oracle，先照这里做一遍，环境就回来了。
> 这份文件不会写任何真实密码 —— 见最后一节。

## 一、这套环境长什么样

```
Windows 电脑
└─ Docker Desktop（容器工厂，必须先启动）
   └─ 容器 oracle-free（gvenzl/oracle-free:23-slim）
      └─ Oracle Database Free 26ai
         ├─ 可用的库（容器）：FREEPDB1   ← 日常都用这个
         └─ 模式（用户）：STUDY          ← 自己的地盘，练习表都在这
```

数据存在 Docker 卷 **`oracle-free-data`** 里，所以**关电脑、重启容器都不会丢数据**。

## 二、每次开机的三步

```powershell
# ① 启动 Docker Desktop（或者点开始菜单图标，等托盘鲸鱼图标不再转）
Start-Process 'C:\Program Files\Docker\Docker\Docker Desktop.exe'

# ② 启动 Oracle 容器（Docker 关了容器就停了，数据不会丢）
docker start oracle-free

# ③ 确认数据库活过来了（看到类似 "1 row" 就是好了，约 1~2 分钟）
docker exec -i oracle-free bash -c "echo 'SELECT 1 FROM dual;' | sqlplus -S / as sysdba"
```

**判断标准**：`docker ps` 里能看到 `oracle-free ... Up ... 0.0.0.0:1521->1521/tcp`。

## 三、常用命令

| 想干什么 | 命令 |
| --- | --- |
| 看容器状态 | `docker ps -a` |
| 启动 / 停止数据库 | `docker start oracle-free` / `docker stop oracle-free` |
| 进数据库敲 SQL（对讲机） | `docker exec -it oracle-free sqlplus / as sysdba` |
| 把 SQL 文件搬进容器 | `docker cp "电脑上的文件.sql" oracle-free:/tmp/lx.sql` |
| 让数据库执行那个文件 | `docker exec -i oracle-free sqlplus / as sysdba "@/tmp/lx.sql"` |
| 看数据库启动日志 | `docker logs --tail 30 oracle-free` |

> `docker exec -it` 里的 `-it` = 交互式终端，适合手动敲；
> 跑脚本用 `-i`（不带 `t`）就够了。

## 四、DBeaver 连接信息

| 项 | 值 |
| --- | --- |
| 主机 | `localhost` |
| 端口 | `1521` |
| 服务名（Service Name） | `FREEPDB1` |
| 用户名 | `study` |
| 密码 | 你自己设的那个（见下） |

## 五、密码怎么找、怎么存（重要）

**Docker 卷里的数据库，密码不在这个文件里，也不在 Git 里。**

- 容器第一次启动时会**随机生成**管理员密码，可以在日志里翻到：
  ```powershell
  docker logs oracle-free 2>&1 | Select-String -Pattern "password"
  ```
- 你自己那个 `study` 账号的密码，是当初用 `CREATE USER study IDENTIFIED BY ...` 设的，
  容器里查不到明文。**忘了就用管理员重设一次：**
  ```sql
  ALTER SESSION SET CONTAINER = FREEPDB1;
  ALTER USER study IDENTIFIED BY 新密码;
  ```

> ⚠️ **铁律**：真实密码、密钥、令牌，绝不写进代码、绝不提交到 Git。
> 这个仓库是公开的，提交上去就永远留在历史记录里了 —— 删掉那一行也没用。
> 所以 `.sql` 文件里一律写「换成你的密码」这种占位符。

## 六、万一数据库起不来

```powershell
docker ps -a                              # 看 oracle-free 的状态和退出码
docker logs --tail 50 oracle-free         # 看它最后说了什么（报错一般写在最后几行）
docker start oracle-free                  # 多半只是没启动，再起一次就好
```

**记住顺序**：先 `docker ps` 看**状态**，再 `docker logs` 看**它说了什么**。
报错信息里通常直接写着答案，先把输出读完再去搜。
