# hello-github

这是我用来学编程的练习仓库，创建于 2026 年。

## 这个仓库是干什么的

不是给别人看的作品，是给我自己的**学习记录本**：

- 每学一个知识点，就在 `NOTES.md` 里记一条，写清楚「今天学了什么、哪里卡住了、怎么解决的」
- 每写一个能跑起来的小练习，就在仓库里新建一个文件夹放进去
- 每天改完东西就提交一次，一年后回看提交历史，能看到自己走过多少路

## 每天的四步

```bash
git pull                  # 1. 先拉最新的（换电脑时尤其要做）
git status                # 2. 看看自己改了哪些文件
git add .                 # 3. 把改动放进待提交的篮子
git commit -m '说明'       # 4. 存一个版本快照
git push                  # 5. 上传到 GitHub
```

> 提交说明用中文完全没问题，写清楚「改了什么」比写得漂亮重要得多。

## 目录说明

| 文件 | 用途 |
| --- | --- |
| `NOTES.md` | 学习日志，一条一条往下记 |
| `.gitignore` | 告诉 Git 哪些文件不用管（临时文件、密码文件等） |
| `README.md` | 就是你现在看的这份说明 |

## 万一改坏了怎么办

这就是用 Git 最大的好处 —— 任何一次提交都是一个「存档点」，随时能回到过去：

```bash
git log --oneline         # 查看所有存档点
git restore 文件名         # 把一个文件恢复到上次提交的状态
```

放心大胆地改，改坏了永远救得回来。
